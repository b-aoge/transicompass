# 转型罗盘 TransiCompass

建筑从业者职业转型决策工具。输入当前岗位、年限、技能、目标方向，生成转型匹配度评估与分阶段行动路线。

## 文件说明
- `app.html` — 单文件应用（HTML + CSS + JS 一体），直接双击或部署到任意静态托管即可运行
- `mockup/` — Apple 风格高保真原型（HTML 源 + 截图），用于设计评审，不参与线上运行

## 部署
将 `app.html` 部署到任意静态托管（WorkBuddy CloudStudio / EdgeOne Pages / GitHub Pages）即可。

## 说明
- 评估算法为前端随机权重混合的演示版，方向库为硬编码 6 条，非生产级模型
- 内置 API Key 仅供演示，请自行替换
