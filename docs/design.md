# 转型罗盘 TransiCompass · 界面设计规范（design.md）

> 适用版本：`v1.15-08202150` ｜ 配套：[PRD.md](./PRD.md)
> 本规范沉淀自 `app/transicompass.html` 的 `:root` 设计 Token 与全部组件样式，**新增 / 修改界面须遵循本文件**，避免风格漂移。

---

## 1. 设计哲学

- **Apple 风 · 近白表面**：背景近白、文字近黑、卡片纯白、弱阴影，大面积留白，克制不花哨。
- **方向蓝 + 罗盘金**：主强调用科技蓝（方向 / 行动），点缀用罗盘金（专业 / 建筑感），绿色用于"成功 / 可迁移高亮"。
- **对话式陪跑感**：步骤条清晰、进度可视、AI 结果用标签 / 高亮 / 卡片即时呈现，降低"转型焦虑"。
- **零门槛一致**：按钮全圆角胶囊、主行动固定蓝色渐变、危险用红、成功用绿，全局统一心智。

## 2. 设计 Token（CSS 变量，改色只动这里）

### 2.1 色彩
```css
--bg:#f5f5f7;        /* 页面底色（近白灰） */
--bg2:#ffffff;       /* 卡片/表面 */
--card:#ffffff;      /* 卡片 */
--line:#e8e8ed;      /* 描边/分割线 */
--text:#1d1d1f;      /* 主文字（近黑） */
--sub:#6e6e73;       /* 次级文字/说明 */
--cyan:#0a6cff;      /* 主强调·方向蓝（实际主色） */
--violet:#0a6cff;    /* 紫（当前等同 cyan，预留） */
--green:#1d8a4f;     /* 成功/可迁移高亮 */
--amber:#e8a33d;     /* 警示/资源提示 */
--red:#d92d20;       /* 错误/危险 */
--shadow:0 4px 28px rgba(0,0,0,.08);
```
> 背景含两个极淡径向渐变（蓝 5% / 金 4.5%）增加质感，不喧宾夺主。

### 2.2 字体
- 字体族：`"Inter","PingFang SC","Microsoft YaHei",system-ui,-apple-system,sans-serif`
- 简历导出专用（Word 一致）：`'Microsoft YaHei','PingFang SC',SimSun,sans-serif`
- 字号梯度：品牌 30 / 步骤标题 20 / 卡片 h2 24 / 正文 16 / 说明 13–15 / 小字 11–12。

### 2.3 间距 & 圆角 & 阴影
- 页面 padding：`52px 40px 90px`；容器 `.wrap` 宽 `96vw / max 1680px`。
- 圆角：卡片 20 / 输入 14 / 小卡 12 / 胶囊按钮 980px（全圆） / 标签 20。
- 主阴影：`--shadow`；悬浮态用蓝色辉光（如 `.step.active` 0 0 24px rgba(10,108,255,.25)）。

## 3. 布局与栅格

- **顶部品牌区**：左 logo+标题（含版本号小字），右两个 Key 配置胶囊按钮（带状态圆点）。
- **trust 区**：一行信任标签（锁/闪/建筑图标）。
- **步骤条 `.steps`**：4 等分 flex，最小宽 220，`@media(max-width:900px)` 自动换行。
- **面板 `.panel`**：默认 `display:none`，`.show` 淡入（`@keyframes fade` 上移 8px）。
- **STEP2 诊断**：左雷达 420px + 右方向卡 `1fr`，`max-width:900px` 改单列。
- **STEP3 简历**：左右两列 `1fr 1fr`，`max-width:900px` 改单列；JD 框与输出框等高（`align-items:stretch`）。
- **STEP4 路径**：单栏卡片纵向堆叠；技能盘点双栏 `1fr 1fr`，`max-width:720px` 改单列。

## 4. 组件规范

### 4.1 按钮 `.btn`
- 主按钮：蓝紫渐变 `linear-gradient(135deg,var(--violet),var(--cyan))`，白字 700，圆角 980px，阴影蓝 22%。
- ghost：透明 + 描边，用于"上一步 / 反馈"。
- hover：`opacity:.92`；disabled：`opacity:.4 + not-allowed`。
- 专用：`.up-btn`、`.job-btn`、`.juse`、`.more-res-btn` 均沿用蓝系，hover 加深蓝底。

### 4.2 步骤条 `.step`
- 未激活：白卡 + 描边；hover 描边变蓝；`.active`：蓝描边 + 蓝辉光 + 标题变蓝。
- 可点击跳转（`data-step`）。

### 4.3 卡片 `.card` / `.dir-card` / `.job-card`
- `.card`：白底、圆角 20、padding `38px 40px`、模糊背景。
- `.dir-card`：左 3px 色条（按方向主色 cyan/violet/green/amber），内含匹配度（右上绿）、名称、理由、标签、岗位按钮。
- `.job-card`：灰底圆角 12，hover 蓝描边；含薪资绿字、来源链接、使用 JD 主按钮。

### 4.4 标签 / 快速词 `.chip` / `.badge` / `.sg-tag`
- `.chip`：未选灰描边，`.on` 蓝底蓝字（STEP1 快速标签）。
- `.badge`：蓝底蓝字小标签（方向卡能力标签）。
- `.sg-tag`：技能盘点用，have=绿底绿字、need=红底红字。

### 4.5 高亮 `.hl`（关键视觉资产）
- 屏幕预览：`background:rgba(52,211,153,.18); color:var(--green); 圆角4; 加粗`。
- 简历导出/复制：`.hl, .rp-list b` → 绿底 `#d1fae5` + 绿字 `#047857`。
- **规则**：AI 改写中 `**加粗**` 关键词即渲染为高亮，是"可迁移能力一眼可见"的核心表达，新功能涉及重点词须复用 `.hl`。

### 4.6 简历纸张 `.resume-paper` / `.rp-*`（投递版式）
- 白底 `#fff`、深字 `#1f2937`、圆角 12、内 padding `34px 42px`、强阴影，max-width 820 居中。
- 5 段式：**求职意向 → 教育经历 → 工作经历 → 项目经历 → 自我评价**，严格对应模板 docx。
- 段标题 `.rp-sec-h`：16pt 蓝 `#0369a1` + 底部细线；姓名居中 26pt 加粗；联系信息底部蓝线。
- 工作/项目分"职责/业绩""职责/描述/业绩"有序列表，与屏幕预览结构一致。

### 4.7 进度条 `.path-progress`
- 高度 10、蓝绿渐变填充、圆角、`transition:width .6s`；4 段文案递进，完成跑满 100% + ✓。

### 4.8 Modal / Toast
- `.modal-overlay`：黑色 60% + 模糊，居中白卡圆角 18。
- Key 配置 Modal 含试用次数进度条（`.trial-remain .bar`，绿/琥珀/红三态）。

## 5. 状态与反馈

| 状态 | 颜色 | 位置示例 |
|---|---|---|
| 成功 | 绿 `#1d8a4f` | 已解析✓、已具备技能、导出成功 |
| 进行中 | 蓝 | loading 旋转、进度条、RPA 日志 |
| 警示 | 琥珀 | 试用剩余 1 次、资源提示 |
| 错误 | 红 `#d92d20` | 解析失败✗、AI 失败回退提示、待补齐技能 |
| 配置 OK | 绿点 | 右上角 Key 圆点 `.dot.ok` |

- **加载**：全局 `.loading-overlay` 旋转 spinner + 文案。
- **AI 回退**：红框提示"已自动切换本地模板"，并附「🔍 诊断信息」可折叠面板。

## 6. 响应式

- 主断点 `900px`：诊断双列、简历双列、步骤条换行 → 单列。
- 次断点 `720px`：技能盘点双栏 → 单列。
- 容器随视口 `96vw`，移动端靠单列堆叠保持可读。

## 7. 简历模板（5 段式，与 docx 对齐）

> 屏幕预览（`.r-*`）与导出（`.rp-*`）共用 `resumeInner()` 数据模型，仅样式层不同。**任何改动须保证两端结构一致**。

1. 求职意向（岗位 + 城市）
2. 教育经历（period / school / major / extra）
3. 工作经历（职责 + 业绩，STAR，`.hl` 高亮）
4. 项目经历（职责 + 描述 + 业绩）
5. 自我评价（3 条，结合建筑背景与目标岗位）

---

## 8. 可访问性 & 一致性约定

- 所有交互元素 `cursor:pointer` + `:hover` 反馈。
- 外部链接 `target="_blank" rel="noopener noreferrer"`。
- 中文 URL 经 `encodeURI` 处理（linkifyUrls）避免裸汉字打不开。
- **新增色 / 组件必须先加 Token 或复用既有类**，禁止散写 `style` 硬编码颜色（统计/调试除外）。
- 版本号固定在标题处（`v1.15-08202150`），改版同步更新并硬刷新部署。
