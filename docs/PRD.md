## 1. 产品概述

**转型罗盘（TransiCompass）** 是一款面向「建筑 / 土木 / 工程行业从业者」的**转行 AI 陪跑**单页 Web 产品。它把"不知道去哪、简历不会写、学了什么不知道"三件最痛的事，浓缩成一条**对话式诊断 → 简历优化 → 学习路径**的闭环流水线，全部在浏览器内完成，无需登录、无后端存储。

产品的定位是**样品 / MVP 验证**：用真实可点可用的交互证明"建筑人转行"这一垂直场景的产品价值，为后续商业化（会员、顾问服务、岗位对接）积累种子用户与需求。

### 1.1 一句话定位
> 专为建筑 / 工程人打造，用 AI 把"10 年现场经验"翻译成"目标岗位看得懂的简历与成长路线"。

### 1.2 核心叙事（4 步）
| 步骤 | 名称 | 用户动作 | 系统交付 |
|---|---|---|---|
| STEP 1 | 自我描述 & 简历 | 填背景 / 传简历 | 结构化自我画像 |
| STEP 2 | AI 定位诊断 | 点"开始诊断" | 6 维能力雷达 + 2+3 个转型方向 + 真实岗位推荐 |
| STEP 3 | 简历优化 | 填 JD / 一键 AI 改写 | STAR 法则改写、可迁移能力高亮的岗位简历 |
| STEP 4 | 学习路径规划 | 点"开始定制" | 技能盘点 + 三阶段路径 + 可点击学习资源 |

## 2. 目标用户与场景

### 2.1 目标人群（画像）
- **核心**：30–45 岁、8–15 年经验的建筑 / 土木 / 工程从业者（施工管理、项目经理、商务报价、供应链、甲方对接）。
- **痛点**：行业下行、想转行但"不知道去哪"；简历停留在工程语境、投产品 / AI / 新能源岗石沉大海；自学无方向。
- **特征**：非互联网背景、STAR / PRD 等新岗位语言不熟、但具备强项目管理与跨职能交付能力。

### 2.2 典型场景
1. 房建项目经理想转 AI 产品经理 → STEP2 给方向，STEP3 把"全周期管理"改写成"产品生命周期"，STEP4 给 PRD / Axure 学习清单。
2. 供应链负责人想转储能出海 BD → STEP3 把"供应商管理"改写成"渠道与伙伴拓展"，STEP4 给出海商务英语 + 行业研报。
3. 仅想"看我能去哪" → STEP1 填一句话 + 快速标签，STEP2 即出雷达与方向，不强制走完。

### 2.3 非目标用户
- 应届生 / 无工作经验者（缺乏可迁移经历，改写效果差）。
- 纯互联网转互联网（不是本产品差异化价值所在）。

---

## 3. 核心价值主张

1. **行业专精**：方向库、术语映射、岗位数据都围绕"建筑→新赛道"，而非通用简历工具。
2. **可迁移能力显性化**：用 STAR + **加粗高亮**让用户一眼看到"我的工程经验 = 目标岗位要什么"。
3. **真实岗位锚定**：STEP2 接入八爪鱼云采集，真实抓取 Boss 直聘岗位，JD 可一键带入 STEP3。
4. **零门槛闭环**：不上传服务器、不登录，Key 本地存，Demo Key 即开即用。
5. **可投递产出**：导出 .docx 简历、可点击学习资源，用户离开产品即能落地。

## 4. 功能详述

### 4.1 STEP 1 · 自我描述 & 简历
- **输入框**：大白话描述背景 / 困惑，内置示例文本（首次聚焦自动清空）。
- **快速标签**：施工管理 / 招投标 / 供应链 / 现场执行 / BIM / 新能源 / 甲方对接 / 团队管理，点击即追加 / 移除关键词到输入框。
- **简历上传**：支持 `.txt / .pdf / .docx`（`.doc` 旧版不支持，引导另存 docx）。
  - txt：直接读文本；docx：mammoth 提取纯文本；pdf：pdfjs-dist 按页提取。
  - 解析后截断到 4000 字填入输入框，状态实时回显（✓ 已解析 / ✗ 失败原因）。

### 4.2 STEP 2 · AI 定位诊断
- **能力雷达（6 维）**：项目管理 / 沟通协调 / 供应链采购 / 风险控制 / 商务报价 / 现场执行，由 `analyze()` 按输入关键词动态打分（58 起 + 命中加权 + 随机抖动）。
- **转型方向卡**：
  - 本行业延续方向（低风险过渡）2 个：工程咨询/甲方 PMO、建筑/基建项目经理（升级）。
  - 跨行业热点方向（新赛道）3–4 个：AI 产品经理(Agent)、具身智能/机器人运营、低空经济、储能/新能源出海 BD。
  - 每张卡含：匹配度%、一句话理由、3 个标签、左侧色条（按方向主色）。
- **AI 实时生成（可选）**：点"开始诊断"调用 DeepSeek 输出 JSON（6 维 + 2 inDirs + 3~4 crossDirs）；失败自动回退本地 `analyze()` 模拟，并标注"非实时"。

### 4.3 STEP 2 · 岗位推荐（八爪鱼 / 模拟 RPA）
- 每张方向卡有「🔍 岗位推荐（点击采集）」按钮 → 调用 `simulateRPA()`：
  - **已配置八爪鱼**：真实调用 `openapi.bazhuayu.com` 云采集（启动任务 → 轮询 lotNo 拉取 → 字段映射 → 按方向过滤），支持分页"更多岗位"。
  - **未配置 / 失败 / CORS 拦截**：回退本地种子数据（`JOBS` 表，每方向 ≥5 条真实感 Boss 结构字段），模拟 RPA 翻页日志。
- **岗位卡字段**：岗位名 / 薪资 / 公司 / 城市·经验·学历·规模·融资 / 标签 / 描述 / 来源链接（跳 zhipin）+「用此 JD 优化简历 →」。
- **去重策略**：每次推荐 Fisher-Yates 洗牌 + 标题前缀变体，避免结果雷同（用户反馈项）。
- 点「用此 JD」→ `buildJDText()` 拼 JD 文本带入 STEP3 输入框并跳转。

### 4.4 STEP 3 · 简历优化
- **左侧 JD 输入**：手动粘贴 / STEP2 一键带入 / 多文件上传（图片 / PDF）。
  - JD 图片：tesseract.js 中文 OCR（预处理放大+灰度提升识别率），识别后自动填入。
  - JD PDF：pdfjs 提取文本层。
  - 缩略图网格，支持「重新识别 / 删除 / 清空全部」。
- **右侧一键 AI 改写**（`rewriteWithAI`）：
  - 把原始简历 + JD 交给 DeepSeek，输出严格 5 段式 canonical JSON（求职意向/教育/工作/项目/自我评价）。
  - 工作 / 项目用 **STAR 法则**改写，分"职责 / 业绩""职责 / 描述 / 业绩"，`**加粗**` 标可迁移关键词（每条 1–3 个）。
  - 公司名 / 项目名 / 时间 / 板块结构**全部保留**，不编造不存在经历。
  - **两次重试机制**：AI 偶发返回空 work/projects 时换更强指令重试；仍失败回退本地模板（`BASE` 术语映射 + `toSTAR`）。
- **预览渲染**（`renderRewritePreview`）：仅展示 AI 改写后的工作 / 项目经历（不含原始简历框架）；完整可投递简历由导出 / 复制提供。
- **复制**：「复制纯文本」（clipboard）/「复制带格式」（ClipboardItem text/html，粘进 Word 保持版式）。
- **高亮**：`.hl` 绿色底高亮可迁移关键词（用户反馈项）。
- **诊断兜底**：AI 失败时展示「🔍 诊断信息」折叠面板（STEP1 字数、JD 字数、AI 原始返回、错误），便于排查。

### 4.5 STEP 4 · 学习路径规划
- **点击触发**（非自动，避免无谓消耗）：进入 STEP4 显示「🚀 开始定制」按钮 → 点后跑**进度条**（4 段：读 JD → 提取能力 → 盘点差距 → 定制路径）。
- **技能盘点**（`gapOut`）：对比 JD 与简历关键词，输出「✅ 已具备技能 / 🚧 待补齐技能」双栏。
- **三阶段路径**（补认知 4–6 周 / 强迁移 6–8 周 / 冲 offer 持续）：
  - 每阶段 3 条 items（做什么 / 交付物）+ 5 条 resources（**平台：… + 真实可点击链接**）。
  - 资源优先国内可访问：B 站 / 极客时间 / 慕课网 / 知乎 / CSDN / 微信读书 / 菜鸟教程 / 稀土掘金；**禁止** Coursera / 国外官网等常超时链接。
  - **每阶段「🔄 推荐更多学习资料」**：单阶段追加调用 DeepSeek 推荐 6 条资源，插入当前阶段列表。
- **AI 生成失败**：回退 `localPlan()`（本地技能映射 + `RESOURCE_MAP` 资源库）+ 进度条仍跑满。

### 4.6 导出 / 反馈 / 统计
- **导出 Word**（`exportBtn`）：仅导出 STEP3 AI 优化简历，按「个人简历模板」5 段式排版（白底专业版式，`.hl` 绿色高亮），文件名 `优化简历_目标岗位_日期.docx`。优先 html-docx-js，CDN 不可用时用**内置零依赖 zip 生成器**兜底输出真实 .docx。
- **意见反馈**（`feedbackBtn`）：跳飞书多维表格表单。
- **网站统计**：已接入 51.LA（`LA.init`，`hashMode:true, autoTrack:true`），事件 `job_recommend_click` 上报方向。

### 4.7 API Key 配置（右上角）
- **DeepSeek Key**：弹窗填 Key，存 localStorage；未填则用**预置 Demo Key**（每个浏览器独立免费试用 9 次，超限提示换 Key / 浏览器）。模型 `deepseek-v4-flash`。
- **八爪鱼 API**：填 x-api-key / Bearer Token / taskId，存 localStorage；预置宝哥共享配置（不限次数）。

## 5. AI 能力与模型

| 能力 | 触发点 | 模型 / 方式 | 输出 |
|---|---|---|---|
| 定位诊断 | STEP2 开始诊断 | DeepSeek（JSON Mode） | 6 维 + 方向卡 JSON |
| 简历改写 | STEP3 一键 AI 改写 | DeepSeek（JSON Mode，2 次重试） | 5 段式 canonical JSON |
| 学习路径 | STEP4 开始定制 | DeepSeek（JSON Mode） | gap + 3 阶段 JSON |
| 更多资源 | STEP4 单阶段按钮 | DeepSeek（JSON Mode） | resources 数组 |
| OCR | JD 图片上传 | tesseract.js（本地，chi_sim+eng） | 文本 |

- **降级原则**：所有 AI 调用失败（无 Key / CORS / 超时 / 解析异常）均回退本地模板，**永不白屏**。
- **根因防护**：`asArr` 区分对象与原始值、空 work/projects 判空重试、`parseJSONSafe` 平衡花括号提取 —— 见飞书 I-9~I-13。

## 6. 数据与隐私

- **不上传服务器**：简历 / JD / Key 仅存浏览器 localStorage（Key 名 `tc_deepseek_key`、`tc_bazhuayu_*`）。
- **统计**：51.LA 仅采集匿名访问行为，无个人简历内容。
- **第三方**：DeepSeek（仅模型推理）、八爪鱼（仅岗位采集，需用户主动配置）、飞书（仅反馈表单）。
- **明示**：首页 trust 区标注「数据仅保存在你浏览器本地」。

## 7. 技术架构与部署

- **形态**：单文件 `transicompass.html`（HTML + CSS + 原生 JS，零构建）。
- **真源位置**：`F:\buddy\转型罗盘TranSiCompass\app\transicompass.html`（**唯一真源**，所有修改在此）。
- **外部依赖（CDN）**：mammoth（docx）、pdfjs-dist（PDF）、tesseract.js（OCR）、html-docx-js（Word 导出）、51.LA（统计）。
- **部署**：CloudStudio 静态站点（workbuddy.link），同会话覆盖更新。
- **统计平台接入方式**：自行编写 HTML 部署（非低代码），统计代码置于 `<head>`。

## 8. 已知限制与降级策略

| 限制 | 表现 | 降级 |
|---|---|---|
| 无 Key / 试用耗尽 | AI 改写 / 诊断不可用 | 本地模板（STAR / 方向库） |
| 八爪鱼未配置 / CORS | 岗位非实时 | 本地种子数据 + 模拟 RPA 日志 |
| .doc 旧版 | 不支持 | 提示另存 .docx |
| CDN 不可达 | docx 导出 / OCR 失败 | 内置 zip 生成器 / 手动粘贴 |
| AI 返回空工作经历 | 预览空白 | 重试 + 诊断面板 |
