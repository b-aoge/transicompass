# ADR-009: 不引入 RAG / 向量库，赛道知识以人工校订静态映射表内置

- Status: Accepted (2026-08-03)
- Deciders: 高见远（架构师）
- Related: ADR-004, ADR-005

## Background

V1 只做深 3 个赛道（新能源与储能 / 智能建造与 BIM / 工程类 B2B 出海），且赛道能力要求、匹配依据是相对稳定、可人工校订的知识。RAG + 向量库适合大规模动态知识检索，但引入检索质量不确定性、额外基础设施与维护成本。

## Decision

将六大赛道能力映射表（实际 V1 用 3 赛道）以**人工校订的静态数据结构**内置在代码/配置中，作为 AI 输出的兜底与校验基准。不引入 pgvector / Milvus / Qdrant 等向量库，不做 embedding 检索。当 AI 输出与静态表严重偏离或 AI 不可用时，以静态表生成基础匹配结果（降级）。

## Consequences

- 正面：匹配逻辑可解释、可审计、零检索不确定性；无额外基础设施；V1 三赛道量级完全够用。
- 负面：知识更新需改代码/配置并重发；跨赛道扩展时需人工维护映射表。V1 范围内可接受。

## Alternatives Considered

- pgvector + 向量检索：适合大规模知识库，但 V1 赛道少且稳定，属于过度工程。否决。
